# Retained Evidence

This directory contains outputs produced by documented repository commands.
The files are retained so a reviewer can compare a fresh run with the baseline
without treating generated results as unsupported promotional claims.

## Files

- evaluation-report.json: per-case decisions and aggregate metrics generated by
  the evaluation command.
- VERIFICATION.md: environment, commands, results, and stated limitations from
  the completed repository verification.

Regenerate the JSON report:

~~~bash
PYTHONPATH=src python -m secure_agent_runtime \
  --policy config/policy.toml \
  evaluate \
  --corpus evals/attack_corpus.jsonl \
  --report evidence/evaluation-report.json
~~~

The corpus is maintained in the same repository as the detector. Results are
therefore regression evidence, not an independent security evaluation.
